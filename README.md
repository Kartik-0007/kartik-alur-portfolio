# Kartik Alur — Resume & Bio-data Website

A beginner-friendly, responsive, five-page personal website built with HTML5, CSS3, JavaScript and jQuery.

## Pages

- `index.html` — Home
- `resume.html` — Resume
- `biodata.html` — Bio-data
- `projects.html` — Projects portfolio (currently an honest empty state; no projects have been added)
- `contact.html` — Contact information and validated email hand-off form

## Features

- Creative gradient-based design with professional content layout
- Dark mode by default and a Light/Dark theme toggle
- Responsive mobile navigation
- Animated homepage introduction
- Scroll reveal effects and back-to-top button
- Contact form validation
- Print / Save as PDF button on the Resume page
- Shared styling and JavaScript across pages

## Run locally

### Option 1: Open directly
1. Extract the ZIP file.
2. Open the `Kartik-Portfolio-Website` folder.
3. Double-click `index.html` to open it in a browser.

### Option 2: Use Visual Studio Code (recommended)
1. Open Visual Studio Code.
2. Select **File → Open Folder**.
3. Select the extracted `Kartik-Portfolio-Website` folder.
4. Open `index.html`.
5. If you have the **Live Server** extension installed, right-click `index.html` and select **Open with Live Server**.

The website's basic HTML and CSS content works locally. jQuery is loaded from its official CDN, and Google Fonts are also loaded online, so an internet connection is needed for those external resources and the jQuery-powered interactions.

## Save the Resume as PDF

1. Open `resume.html` in your browser.
2. Select **Print / Save as PDF**.
3. In the print dialog, choose **Save as PDF** as the destination.
4. Save the generated PDF to your computer.

The PDF is generated by your browser's print feature. No separate resume PDF was supplied with this project.

## Contact form behaviour

The contact form checks that all fields are completed and that the email address has a valid format. It then opens the visitor's default email application with a pre-filled message addressed to `kartikalur595@gmail.com`.

The website does **not** send or store messages itself. A backend or a form service would be needed for direct website submissions.

## Personalization

The content is based on details previously confirmed for this website. Review all details before publishing. To update the site, edit the relevant HTML file and save it.

- Update navigation or shared interactions in the HTML pages / `js/script.js`.
- Update colors, layout and responsive behaviour in `css/style.css`.
- Add future projects to `projects.html` only when they are completed and ready to describe.
- Add a real PDF file separately if you want a direct PDF download link.

## Print the resume as a one-page A4 PDF

Open `resume.html`, select **Print / Save as PDF**, and in the browser print dialog choose:
- Destination: **Save as PDF**
- Paper size: **A4**
- Scale: **100%** (use **Fit to printable area** only if your browser clips content)
- Margins: **Default**
- Headers and footers: **Off**

The resume page uses a separate print stylesheet, so its compact A4 layout does not change the normal website appearance.


## Print the Bio-data as a one-page A4 PDF

1. Open `biodata.html` in the browser.
2. Click **Print / Save as PDF**.
3. In the print dialog, choose **Save as PDF** and **A4** paper.
4. Use **100%** scale, **Default** margins, and turn **Headers and footers** off.
5. Check the preview shows one page before saving.

The Bio-data has its own print-only layout. Its normal on-screen design is unchanged.
