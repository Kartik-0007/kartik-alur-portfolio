# Kartik Alur Portfolio Website — Print Ready

This package contains the five-page responsive portfolio website:

- `index.html` — Home (includes the profile photo)
- `resume.html` — Resume
- `biodata.html` — Bio-data
- `projects.html` — Projects (Online Harassment Detection System, marked In Progress)
- `contact.html` — Contact

## Run locally

1. Extract the ZIP file.
2. Keep the `css`, `js`, and `assets` folders beside the five HTML files.
3. Open `index.html` in Chrome or Edge.

## Print or save any page as a colour PDF

1. Open the page you want to print.
2. Select **Print / Save as PDF** on the page, or press `Ctrl + P`.
3. Choose **Save as PDF** or **Microsoft Print to PDF**.
4. In the browser print dialog, open **More settings** and enable **Background graphics**.
5. Choose **Colour** (not Grayscale), if that option is available, then print/save.

The print stylesheet is shared by all five pages. It keeps the dark navy and blue/cyan accents, reduces large blank gaps, and lets the content flow naturally across A4 pages. Browser/printer settings can still suppress background colours if Background graphics is disabled.
